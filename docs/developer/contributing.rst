文档维护与用例扩展
========================================

新增章节
----------------------------------------

用户操作放在 ``user/``，开发实现和构建流程放在 ``developer/``。
新增 ``.rst`` 文件后，将不带扩展名的相对路径加入所属目录 ``index.rst`` 的 toctree。
新增协议实验可复制用户指南的 BGP IPv4 实验结构。

写作要求
----------------------------------------

* 写明命令执行位置、所需镜像、工作目录和状态文件。
* 区分已验证步骤、示例和待补充内容。
* 协议配置和验证输出注明适用版本。
* 说明配置保存与清理方式，避免只记录创建步骤。
* 图片和抓包采用相对路径引用，不使用个人机器的绝对路径。

提交前检查
----------------------------------------

在文档目录执行 ``make check`` 和 ``make html``；调整排版或发布时再构建 PDF。
检查用户和开发两套导航、版本选择器，以及示例与脚本帮助是否一致。

提交前使用 ``git status`` 核对变更范围。当前 HTML、PDF 和中间产物由
``docs/.gitignore`` 忽略；``versions/`` 历史发布是否纳入版本控制由项目交付方式决定。
不要把实验运行状态、容器清单和 Python 缓存当作文档源码提交。
