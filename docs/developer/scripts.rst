脚本开发
========================================

入口职责
----------------------------------------

``frr_init.sh``
   Bash 命令行入口，处理 FRR 容器创建和回收、netns 登记、抓包及拓扑调用。
``frr_topology.py``
   使用 Python 标准库采集 Docker/OVS 状态，调用宿主机 Graphviz 渲染 SVG。
``frr_vpcs.py``
   管理容器间专用 veth，复用拓扑模块的命令执行和异常封装。

扩展约定
----------------------------------------

* 参数解析先完成检查，再执行有副作用的操作。
* netns 操作核对容器 PID 和命名空间归属；容器名相同不代表仍是原实例。
* VPCS 操作保留状态文件、锁、所有权校验及失败回滚。
* 拓扑采集保持只读；无法确认的连接应给出警告，避免推测成已验证链路。
* 新命令同步更新帮助、用户文档和对应行为测试。

VPCS 状态
----------------------------------------

当前状态格式版本为 ``2``，顶层包含 ``version`` 和 ``pcs``。
连接记录包含端点与操作阶段；创建过程可能出现 ``creating``、``ready``、
``cleanup-required``。结构发生变化时需定义兼容和清理路径。
